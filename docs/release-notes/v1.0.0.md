Zipnami picks a random real Japanese postal code and shows every address it
covers, at the press of one button: https://zipnami.pages.dev

v1.0.0 completes the Web MVP tracked in #22.

## What is new since v0.1.0

- **Guide pages.** Five original guide pages, reachable from the footer, each
  ending with a link back to the generator (#121, #129, #130).
- **Ads only where there is content.** Ads are requested only on the result
  screen. The start, loading, error, not-found, and privacy screens load no
  advertising code (#120, #128).
- **Design.** The desktop result follows the Figma layout, and every header
  shows the logo (#117, #122).
- **Fixes.** The privacy page's footer link goes home (#119), and the AdSense
  consent steps in the deployment guide are current (#123).

## What the site does

- Picks a uniformly random postal code from the full Japan Post dataset.
- Shows every address for that code on a map, with a link to Google Maps.
- Copies the code, and keeps a history of earlier results in the browser.
- Works on phones, tablets, and desktops, in Google Chrome, Microsoft Edge,
  and Safari, and meets WCAG 2.2 AA in the tested flows.
